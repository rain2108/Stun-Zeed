## 📋 Project Overview
Zoo Darshan is India's first online streaming platform for zoos, designed to connect people with wildlife from the comfort of their homes. Our platform enables users to:
- Watch live streams of zoo animals
- Learn about different species and conservation efforts
- Read educational blog content about wildlife
- Experience virtual safari tours

## 🛠️ Technologies Used
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (MongoDB Atlas)
- **Authentication**: Passport.js
- **Other Libraries**: 
  - GSAP (for animations)
  - Owl Carousel
  - Bootstrap

## 🔑 Key Features
- User authentication (signup/login)
- Live animal streaming
- Interactive and responsive UI
- Educational blog with wildlife articles
- Virtual zoo experiences

## 🚀 Getting Started

### Prerequisites
- Node.js
- MongoDB

### Installation
1. Clone the repository
```
git clone https://github.com/your-username/Stun-Zeed.git
```

2. Install dependencies
```
npm install
```

3. Start the server
```
npm run dev
```

4. Access the application
```
http://localhost:4001
```
